# Nave for Windows

Nave helps churches record services, transcribe sermons, and prepare notes for review.

## Download

Download the Windows x64 installer from [Releases](https://github.com/emmanueloladebo/nave-releases/releases/latest). Run the installer over your existing installation; you do not need to uninstall first.

Nave 0.1.4 introduces signed in-app updates. If you use 0.1.3 or an earlier version, install 0.1.4 manually once. Future updates appear when you open Nave and can also be checked in Settings.

The installer currently has no Windows publisher certificate, so Windows may show an unknown publisher warning. In-app updates are verified using Nave's updater signature.

This repository contains public downloads only. Application source code is maintained privately.
